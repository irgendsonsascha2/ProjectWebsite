# Laravel-Auth (Hybrid)

Diese App übernimmt Login, Registrierung mit Invite-Code und Passwort-Reset für die klassische PHP-Site. Konfiguration nur über `laravel/.env` (Vorlage: `.env.example`).

**Setup, Handoff, lokaler Start:** siehe [README.md](../README.md) (Abschnitt Laravel / Hybrid-Authentifizierung) und [AGENTS.md](../AGENTS.md).
